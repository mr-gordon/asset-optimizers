# Image Compressor App 🖼️

[![Version](https://img.shields.io/badge/version-v1.8.0-blue.svg)](https://github.com/mr-gordon/asset-optimizers)
[![100% Client-Side](https://img.shields.io/badge/Privacy-100%25%20Client--Side-emerald)](https://github.com/mr-gordon/asset-optimizers)

High-performance, 100% client-side batch image compression & format conversion application built with React 19, TypeScript, and Vite.

## 🌟 Key Features

- **100% Private & Local Processing**: All image operations happen locally inside the browser.
- **Auto & Pro Modes**: One-click automatic optimization or full manual control over target format, quality, dimensions, aspect ratio presets, chroma subsampling (`4:4:4`, `4:2:0`), and EXIF policies.
- **Multi-Format Conversion**: Supports `.jpg`, `.png`, `.webp`, `.avif`, `.gif`, and `.svg`.
- **2.5× Loupe Zoom Magnifier**: Pixel-accurate, distortion-free loupe magnifier for inspecting compression quality side-by-side with original.
- **Inspector Modal & Inline Filename Editing**: Click filename in inspector modal to edit inline.
- **Keyboard Shortcuts & Batch Export**: Download individual files or export bulk batches as `.zip`.
