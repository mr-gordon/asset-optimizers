# SVG Optimizer App ⚡️

[![Version](https://img.shields.io/badge/version-v1.6.5-blue.svg)](https://github.com/mr-gordon/asset-optimizers)
[![100% Client-Side](https://img.shields.io/badge/Privacy-100%25%20Client--Side-emerald)](https://github.com/mr-gordon/asset-optimizers)

Dedicated high-efficiency SVG vector icon optimization, recoloring, and PNG rendering web application.

## 🌟 Key Features

- **Inline SVG Optimization**: Minify SVG code, strip unused attributes, clean IDs & classes, and remove redundant metadata.
- **Dynamic Recoloring & Presets**: Swap `currentColor` or apply custom hex palettes with history tracking.
- **Transparent PNG Export**: Export SVGs to high-resolution PNGs (`1x`, `2x`, `4x`, `8x`) with transparent background defaults.
- **Combined ZIP Export**: Save all optimized SVGs and transparent PNGs together in a single ZIP file (`Save all`).
- **Inspector Modal with Code Editing & Inline Filename Editing**: Inspect SVG code side-by-side with preview, edit code live, and click filename `<h3>` to rename icons inline.
- **Dimension Presets**: Presets (`20, 24, 32, 48, 64, 96px`) for standard icon sizes.
